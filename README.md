# Atelier (public snapshot)

Static, read-only export of the Atelier design tracker for GitHub Pages.
Generated by `scripts/export_github.sh`; do not edit by hand.

- Status changes are saved in your browser only (localStorage).
- Add team is not available here.
- The "Sign in with your Flam ID" screen is identification and personalisation only, not security: it checks the
  address ends in @flamapp.com but cannot verify it, and this public copy has no password gate. Your name, settings
  (start view, team, date range, density) and pinned projects are stored in this browser (localStorage) per email.
- Every signed-in person sees every team (Radhika, Deepak, Global Team, all teams).
- Pipeline: upcoming briefs come from the tracker data; the production pipeline fills once the pipeline Slack channel is added.
- Deck PDFs are not hosted; decks link to Slack (or name their original source). First-page thumbnails are included.
