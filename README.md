# Atelier (public snapshot)

Static, read-only export of the Atelier design tracker for GitHub Pages.
Generated by `scripts/export_github.sh`; do not edit by hand.

- Status changes are saved in your browser only (localStorage).
- Add team is not available here.
- Deck PDFs are not hosted; decks link to Slack (or name their original source). First-page thumbnails are included.
